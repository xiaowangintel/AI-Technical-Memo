## Key Concepts / 关键概念

- **Epilogue flow / Epilogue 流程**: Describes how accumulators are transformed and written to output tensors. / 说明如何将累加结果变换并写回输出张量。
- **Asynchronous copies / 异步拷贝**: Uses asynchronous shared-memory staging to feed the mainloop. / 使用异步共享内存搬运为主循环供数。
- **Vector-matrix flow / 向量-矩阵流程**: Implements GEMV-style logic rather than full matrix-matrix tiling. / 实现 GEMV 风格逻辑，而非完整的矩阵-矩阵分块。
